# Häuser

Der Ordner [Biografien](biografien) enthält alle bisher aus dem Spreadsheet nach Markdown übertragenen Hausbiographien.

Beachte: Die Links in den Dateien sind für die Website gemacht. Beispielsweise in DB0001.md ein Link zu einem einzelnen Eintrag in der Edition (`viewer.html?entry=KB-E-013-3&ansicht=formular`) und zur Hausbiografie eines Nachbarhauses (`info.html?p=daten/haeuser/biografien/DB0002`).
