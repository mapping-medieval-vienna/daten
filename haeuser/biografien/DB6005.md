# DB6005

## Hausbiographie

genannt das große Haus  
Scheffstraße  

Ortolf **Grefenawer**  
erbe: Kinder Barbara, Dorothe, Wolfgang  

erbteilung: A an Barbara, B an Dorothe

das kann sich einfach auf A / B 1439 bis 1448 beziehen, die Beschreibung passt
